# Taotie (饕餮)

Dedicated Chinese Collection product. The previous name “Qilin” was incorrect.

- Collection: paid `/chinese` (`chinese-collection`)
- Grid: 120 columns x 110 rows
- Palette: 12 custom letter codes; 5,699 beads
- `pattern.json`: authoritative cell data and counts
- `grid.csv`: row/column letter chart
- `preview.png`: subject preview
- `finished-photo.png`: owner-provided finished-piece photo for the product page
- `Taotie-Bead-Pattern-English.pdf`: English overview and nine chart sections
- `chart-detail-preview.png`: page preview rendered from a coordinate-chart PDF page
- `render-english.py`: rebuilds the PDF and its detail preview from files in this directory

Use this directory for subsequent Taotie revisions. Earlier files under `output/beads-en` and the 涂鸦网站 workspace are historical copies, not the maintained product source. Preserve the approved pattern unless the owner requests artwork changes.
